# Contributing

## Workflow

1. Create an issue describing your work.
2. Create a feature branch from main.
3. Implement your changes.
4. Run relevant tests.
5. Open a pull request.
6. Obtain at least one review before merging.

## Branch Naming

- feat/feature-name
- fix/bug-name
- docs/document-name
- research/experiment-name

## Commit Conventions

- feat: new functionality
- fix: bug fix
- docs: documentation
- test: testing changes
- chore: maintenance

Do not push secrets or student data.
